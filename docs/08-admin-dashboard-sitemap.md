## Dashboard Metrics

- إجمالي المستخدمين.
- المستخدمون الجدد.
- المعارض الموثقة وتحت المراجعة.
- السيارات المنشورة وتحت المراجعة.
- المزادات القادمة والحالية والمنتهية.
- إجمالي المبيعات.
- الإيرادات والعمولات والعربونات.
- طلبات الفحص.
- الفنيون.
- الإعلانات النشطة.
- الشكاوى والنزاعات.
- المدفوعات الفاشلة.
