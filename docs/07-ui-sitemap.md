## UX Rules

- قبل أي مزايدة يظهر breakdown: مبلغ المزايدة، الرسوم، العربون المتوقع، الالتزام.
- كل إعلان يحمل label: `إعلان` أو `ممول`.
- الوقت المتبقي والسعر الحالي واضحان دائماً في صفحات المزاد.
- لا تعرض أرقام الهواتف أو الوثائق الحساسة إلا حسب سياسة المنصة.
